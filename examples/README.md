# OpenSketch examples

`antibody-mediated-immune-response.OpenSketch` is an editable project containing
an antibody, a T cell, vector structure, attached connector, and accessible
scientific description. Import it from the OpenSketch project home screen.

`antibody-mediated-immune-response.svg` is the corresponding publication-vector
export. Its metadata retains the global NIH BioArt credit plus the source,
author, license, family, and variant identifiers for each bundled illustration.

The three additional project/SVG pairs are generated from OpenSketch's editable
starter layouts:

- `signaling-cascade` — an activation pathway with an orthogonally routed
  inhibitory connector;
- `experimental-workflow` — a four-stage methods figure;
- `comparative-panels` — control/treatment panels with a quantitative summary.

All files are regression artifacts generated through the normal browser editor
workflow. The NIH SVG artwork remains public domain; the project structure and
other software-authored content follow the repository license.
