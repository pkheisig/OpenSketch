# OpenSketch AI BioArt asset inventory

This inventory defines the target scope for the coherent first-party AI-generated BioArt-style library.

## Selection rule

Generate **visually distinct, reusable scientific primitives**, not biological names for their own sake. If two named entities would be indistinguishable in an unlabeled schematic, represent them with one generic archetype instead of separate assets. Create a named asset when morphology, architecture, topology, or experimental form is meaningfully different (for example CD4 versus CD8, MHC-I versus MHC-II, GPCR versus receptor tyrosine kinase).

Each asset should be usable as an isolated building block for larger OpenSketch composites rather than being a complete pathway, workflow, or multi-panel figure.

- Named cytokines and chemokines
- Individual kinases and phosphatases

- Individual small-molecule drugs
- Individual metabolites
- Closely related bacterial species with indistinguishable cell morphology
- Closely related viral strains with the same virion architecture
- Mouse strains that are visually identical apart from coat color or genotype

## Generation principle

The goal is not to maximize the raw asset count. The goal is a visually coherent library in which every generated item adds a genuinely useful new building block. When a user needs a biological identity that has no unique appearance, use the appropriate generic visual archetype and add the biological name as text in the final OpenSketch composition instead of generating redundant artwork.
