# Scientific asset planning review contract

- Review question: Which useful scientific primitives and reusable assemblies extend the frozen OpenSketch inventory without duplicating its 768 distinct names?
- Reader: Paul and a future Astra implementation agent.
- Retrieval cutoff: 2026-09-05.
- Unit: an independently written scientific design specification, with separately identified factual evidence and proposed visual design.
- Scope: a broad, deliberately selected expansion across immune reactions, cell biology, genetics, microbiology, tissues, plant biology and experimental workflows. This is not an exhaustive census of biology or of any commercial catalog.
- Include: official scientific databases and institutional technical documentation; primary papers when needed to verify a specific method. Include only sources whose relevant content was actually retrieved. Name proposed ideas separately from verified mechanisms.
- Exclude: BioRender assets, screenshots, descriptions, catalog metadata, template layouts and account content; unverified exact molecular geometry; clinical instructions; asset generation and app changes.
- Dates: foundational and current references; English source text.
- Comparison axes: scientific identity, meaningful visual distinction, baseline reuse, assembly dependencies, topology and direction, useful states, evidence scope and remaining uncertainty.
- Search map: Reactome for pathway events; official structural and ontology resources for molecular building blocks; institutional method documentation for workflows. Web search discovers sources; opened pages provide evidence.
- Planned synthesis: prioritize reuse, map composite components to exact baseline names, record new primitives separately, and distinguish detailed specifications extending the existing assembly roadmap from genuinely new composite concepts.
- Deliverables: README instructions, Markdown catalog, machine-readable catalog, baseline snapshot hashes, source ledger, claim-evidence matrix and validation report.
- Publication: a separate planning branch based on experimental/ai-bioart-assets-20260904 at f76212775d0fc1af43c7079964b5d22cfecf6324; preserve the active asset-production worktree and its dirty progress files.
- Limits: schematic scientific verification is not structural validation or a publication-ready figure review. Pending baseline items are dependencies, not available generated assets.
