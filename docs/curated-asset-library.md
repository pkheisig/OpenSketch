# Curated library snapshot

611 distinct generated SVGs from committed artwork `6b27cdc1764851bae4e55ac346879be254815b56`, representing 629 completed generation concepts. The app also includes 17 editable structures and two fixed circular membranes. The generation worktree remains independently owned and is not modified by this import.

All 768 planned concepts have explicit categories, topics and keywords in [curated-metadata.json](scientific-asset-planning/curated-metadata.json). The original inventory is unchanged. Identical source SVG digests are deduplicated and existing canonical IDs are retained. Historical aliases record generation history; they are not biological synonyms. These are schematic illustrations, not validated molecular structures.

Empty categories are hidden in the current sidebar. Category selection uses the complete catalog so searching or selecting Favorites cannot erase the category controls. Topic and editability filters can be combined with text search and categories.

Retired external asset files, import scripts, generated catalogs and export provenance fields are removed from the shipped app. Historical planning records and embedded geometry in user projects are preserved; this is not a rewrite of Git history. Font licensing notices and the application license remain.

Validation includes catalog uniqueness, metadata completeness, 4,000-path and 48-color derivative bounds, all shipped SVG hashes, thumbnail existence, source exclusion in exports, saved-project compatibility, and browser interactions. Rendered catalog sheets were inspected for recognizable objects and derivative integrity; this does not constitute a guarantee of every scientific detail.
