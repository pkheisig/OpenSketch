# Security policy

Please report suspected SVG-sanitization bypasses, malicious project-file behavior,
path traversal, or unintended network access privately to `pkheisig@gmail.com`.
Do not open a public issue until the report has been assessed.

Include the smallest reproducible file, OpenSketch version or commit, browser and
operating system, and the observed network or execution behavior. Do not include
confidential scientific data.

OpenSketch has no hosted backend and keeps projects in browser storage, but imported
SVG and portable project files still cross a trust boundary. Security fixes for
those inputs receive priority.
